# Как помочь проекту

Спасибо за интерес! Проект учебный, но правки приветствуются.

## Окружение

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # секреты только здесь, .env в .gitignore
```

## Перед отправкой правок

1. Запустите тесты — они офлайн, сеть не нужна:

   ```bash
   python3 -m pytest
   ```

2. Соблюдайте соглашения проекта:
   - тексты, docstring и комментарии — на русском; имена в коде — на английском;
   - сообщения коммитов — краткие, императивные, на английском
     (например, `Add Telegram command menu via setMyCommands`);
   - основная ветка — `main`.

3. Если добавляете площадку или меняете формат сводки — обновите тесты
   и `README.md`.

## Архитектурные заметки

- Новую площадку добавляйте в `app/sources/` по образцу существующих
  и регистрируйте в `app/sources/__init__.py::build_sources`.
- Упавшая площадка не должна ломать сводку: её ошибка идёт в «Примечания».
- Отправку сообщений в Telegram делайте через `app/rich.py::send_rich` —
  там обеспечивается Rich-оформление и откат на текст.
- Состояние — JSON-файл (`app/subscribers.py`); БД и ORM намеренно не используются.

## Сообщения об ошибках

Опишите: шаги воспроизведения, ожидаемое и фактическое поведение,
версию Python и релевантный фрагмент лога (без секретов из `.env`).
