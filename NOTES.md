# NOTES

Короткие заметки по проекту. Подробности — в `README.md`.

## Что это

Телеграм-бот, который собирает погоду и состояние моря для Адлера (Сочи) сразу
с нескольких площадок и выдаёт обобщённую сводку. Плюс: детектор опасных событий
и рассылка (утренняя сводка в 07:30 МСК и оповещения за час до события).

Учебный (тестовый) проект. Точка прогноза задаётся координатами в `.env`,
геокодирования по названию города нет.

## Карта кода

| Файл | Роль |
| --- | --- |
| `app/config.py` | `Settings` из `.env` (точка, ключи, пороги) |
| `app/sources/` | площадки: Open-Meteo, OpenWeatherMap, wttr.in, Open-Meteo Marine, USGS |
| `app/models.py`, `app/codes.py`, `app/wmo.py`, `app/wwo.py`, `app/timeutil.py` | нормализация данных и кодов погоды |
| `app/aggregate.py` | медиана по площадкам, разброс, круговое среднее, почасовой консенсус |
| `app/events.py` | детектор опасных событий (пороги из настроек) |
| `app/formatting.py` | текст сводки (разделы включаются выборочно) |
| `app/service.py` | сбор сводки + кэш на 5 минут |
| `app/subscribers.py`, `app/notify.py` | подписки в JSON и расписание рассылки |
| `app/bot.py` | aiogram 3: команды, кнопки, фоновый цикл рассылки |
| `app/lockfile.py` | блокировка `state/bot.lock` (второй экземпляр запускать нельзя) |
| `run_bot.py`, `weather_report.py` | точки входа: бот и CLI-сводка |

## Шпаргалка по командам

```bash
python3 run_bot.py --check          # проверить токен (getMe)
python3 run_bot.py --events         # события ближайших часов в консоль
python3 run_bot.py --notify-dry     # что ушло бы подписчикам (состояние не меняется)
python3 run_bot.py --notify-test    # проверочное сообщение подписчикам

python3 weather_report.py --out hello.txt   # сводка в файл
python3 weather_report.py --sections current,events,forecast --days 1

python3 -m pytest                   # тесты, сеть не используется
```

## Что помнить при работе с кодом

- Площадка может упасть — сводка не должна ломаться: ошибка уходит в «Примечания».
- OpenWeatherMap работает только при наличии ключа, без него площадка пропускается.
- Тесты офлайн, на фикстурах в `tests/fixtures/`; фикстуры OpenWeatherMap синтетические
  (ключа не было) — см. поле `"_note"` внутри файлов.
- Рассылка живёт внутри процесса бота: отдельных таймеров и крона нет.
- Секреты только в `.env` (в `.gitignore`); `state/`, `*.log` тоже не коммитятся.
- Тексты и docstring — на русском, имена в коде — на английском.
- Развёртывание — systemd-юнит `weather-bot.service`, рабочая папка
  `/home/botuser/bots/weather-bot`, логи в `logs/bot.log`.
