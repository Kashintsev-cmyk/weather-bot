# test

Учебный (тестовый) проект для проверки и отработки базовых операций с репозиторием Git.

## О проекте

**test** — это стартовый проект-заготовка. На данный момент он не содержит
исходного кода и представляет собой чистую основу, на которой будут
появляться исходные файлы, конфигурация и документация.

## Текущее состояние

```
test-project/
└── README.md
```

## Требования

- [Git](https://git-scm.com/) — для работы с версиями проекта.

## Начало работы

Клонирование репозитория:

```bash
git clone <URL-репозитория>
cd test-project
```

Проверка состояния репозитория:

```bash
git status
```
